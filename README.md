ik vermeld hier de opdracht en hoe je het runt:

hoe run je het:
1. download de code en zet hem ergens in je folders.
2. ga na waar je code staat
3. klik op de balk waar de locatie van je code staat.
4. verander wat er staat ma "cmd" (dit opent je comands)
5. run de code "php -S localhost:8000 (naam code bv. index.php)"
6. je ziet nu een link na een pagina
8. copy de link en paste hem in welke search engine je gebruikt
9. nu is je website zichtwaar

de opdracht:
# backend-Opdracht-Fibonacci-en-tafelkaart
de backend opdracht Opdracht Fibonacci en tafelkaart (met gebruik van functies)

Fibonacci
In deze miniopdracht maak je een functie (zoals bij opdracht functies maken) waarbij je de fibonacci-reeks op het scherm weergeeft. De gebruiker voert een getal in, en het programma genereerd tot n(=ingevoerd getal) zoveel stappen de Fibonacci-reeks. Gebruik hierbij je favoriete programmeertaal. 

Hier de output bij een voorbeeld n=8

1, 2, 3, 5, 8, 13, 21, 34

Tip: gebruik een for-loop

Tafelkaart
In deze miniopdracht maak je een nieuwe functie waarbij je tafelkaart genereerd. De gebruiker voert een getal in, en het programma genereerd van 1 tot n een tabel.

Hier de output bij een voorbeeld n=10
